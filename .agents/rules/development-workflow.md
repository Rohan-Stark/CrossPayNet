# Development Workflow Rules

All major work on CrossPayNet must follow this required workflow:

1. **Understand**: Analyze the task, inspect the existing codebase, and clarify requirements.
2. **Plan**: Produce a detailed implementation plan before writing or changing any code.
3. **Review**: Present the implementation plan for explicit user approval.
4. **Implement**: Write the code as approved in the plan. Keep changes strictly scoped to the task.
5. **Test**: Write and execute appropriate tests (unit, integration, etc.).
6. **Review**: Validate that the code works as expected and meets acceptance criteria.
7. **Document**: Update architecture docs, create ADRs, write API docs, and ensure inline documentation is correct.

**Important**: Major work should *always* produce an implementation plan before code is changed.
